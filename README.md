# Tomasz Catello Grabarczuk — Personal Website

Sito personale statico pronto per il deploy su Vercel.

## Struttura

- `index.html` — homepage bianca con dettagli verdi
- `styles.css` — stile della homepage
- `vela.html` — pagina separata Vela & Boat Systems / BIB SEA 96
- `vela.css` — stile della pagina vela
- `assets/` — immagini ottimizzate per il web
- `vercel.json` — configurazione Vercel e header di sicurezza
- `404.html` — pagina di errore personalizzata

## Deploy su Vercel

1. Vercel → **Add New → Project**
2. Importare `Tomasz-seasonsjob/Tomasz-Catello-Grabarczuk`
3. Framework Preset: **Other**
4. Nessun Build Command necessario
5. Deploy

Dopo il primo collegamento GitHub ↔ Vercel, ogni commit su `main` genera automaticamente un nuovo deploy.

## Modifiche future

Le modifiche al sito vengono fatte nel repository GitHub. Il link SeasonsJob presente nella homepage è provvisorio e può essere sostituito quando sarà disponibile il dominio definitivo.
